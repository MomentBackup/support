# MomentBackup Support

This is the public support home for **MomentBackup**.

MomentBackup protects files and whole computers using storage you control. This
repository holds no product code and no private customer reports.

## Get help

**[Ask a public question](https://github.com/MomentBackup/support/discussions)**

Public answers stay searchable and can help the next person too. The guides may
already have what you need:

- [Getting started](https://momentbackup.com/help/getting-started/)
- [Restore files](https://momentbackup.com/help/getting-files-back/)
- [All help guides](https://momentbackup.com/help/)

## Report a problem

Use the **[private MomentBackup report form](https://momentbackup.com/support/#report)**
for the normal path. It gives you a private `MB-######` reference and update
emails.

Technical users may instead open a **[public GitHub report](https://github.com/MomentBackup/support/issues/new/choose)**
when every detail is safe to share. GitHub issues are public. Do not include
email addresses, file paths, backup names, logs, diagnostics, account details,
storage addresses, screenshots with private data, or credentials.

## Security issues

Do not open a public issue or Discussion for a security problem.

Use [private vulnerability reporting](https://github.com/MomentBackup/support/security/advisories/new).
Only MomentBackup maintainers can see it.
