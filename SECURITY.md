# Security policy

Please do not report a security problem in a public issue or Discussion.

Use [GitHub private vulnerability reporting](https://github.com/MomentBackup/support/security/advisories/new).
Only MomentBackup maintainers can read that report while it is being checked.

Do not include backup contents, credentials, recovery keys, or encryption keys.
If a maintainer needs more detail, they will ask through the private report.
